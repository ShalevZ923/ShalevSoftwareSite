# Security policy

## Supported versions

Security fixes are made against the current `main` branch and the latest
published release.

## Reporting a vulnerability

Please use GitHub's private security-advisory reporting feature for this
repository. Do not open a public issue, discussion, or pull request for a
potential vulnerability until the maintainer has confirmed a disclosure plan.

Include a concise description, affected component and version, reproduction
steps, impact, and any suggested mitigation. Do not include credentials,
private customer data, or unredacted access tokens.

The maintainer will acknowledge a valid report within seven days, assess it,
coordinate a fix, and publish a credit or advisory only with the reporter's
agreement where practical.

## Scope

The public static catalog, container/IIS deployment assets, catalog-validation
tools, and optional local Developer Studio are in scope. Hosted vendors,
third-party installers, external deployment hosts, and credentials outside this
repository require their own reporting channels.
