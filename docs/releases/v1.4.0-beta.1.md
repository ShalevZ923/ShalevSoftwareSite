# Tool Atlas v1.4.0-beta.1

## Included

- Windows-hosted installer support with hardened NGINX and IIS download paths.
- Developer Studio proof-of-concept hardening: loopback default, fragment-only token bootstrap, query-token rejection, URI safety, static-root and symlink containment, and session clearing on exit.
- Catalog loads with every software row collapsed until selected.
- Pull-request CI, static production-image smoke testing, tagged GHCR publication, and OCI provenance attestation.

## Beta limitations

- Developer Studio is local-only administrative tooling, not a multi-user production control plane.
- The Studio’s broader visual refresh requested by issue #5 remains open; this release fixes only its collapsed-catalog bug.
- Windows/IIS, public TLS, external firewall, image digest, and rollback checks remain required production acceptance evidence.
