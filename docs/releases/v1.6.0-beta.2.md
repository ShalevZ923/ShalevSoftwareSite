# Tool Atlas v1.6.0-beta.2

`v1.6.0-beta.2` is a public prerelease containing documentation and catalog presentation refinements after `v1.6.0-beta.1`.

## Highlights

- The README documents the supported GHCR container workflow and keeps local Developer Studio operation separate from the static production image.
- The jq catalog guide now describes hosted package delivery directly, without proof-of-concept framing.
- Completed and unreferenced design-planning materials were removed while active operating and deployment guidance remains available.

## Published artifacts

- Source tag: [`v1.6.0-beta.2`](https://github.com/ShalevZ923/ShalevSoftwareSite/tree/v1.6.0-beta.2)
- GitHub prerelease: [`v1.6.0-beta.2`](https://github.com/ShalevZ923/ShalevSoftwareSite/releases/tag/v1.6.0-beta.2)
- Linux/amd64 image: `ghcr.io/shalevz923/shalevsoftwaresite:1.6.0-beta.2`

The tag workflow verifies source and production artifacts, builds and pushes the image, and publishes an OCI provenance attestation. Use the immutable digest reported by the completed workflow rather than a mutable image tag for production deployment.

## Beta boundary

This image serves only the static public catalog. Developer Studio remains a local, authenticated authoring tool and is not included in a public deployment.
