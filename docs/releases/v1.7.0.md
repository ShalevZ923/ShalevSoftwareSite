# Tool Atlas v1.7.0

`v1.7.0` hardens the static software catalog and documents a companion MCP server. The production image remains NGINX-only. Agent and skills catalog work stays out of this release.

## Highlights

- Navigation announces the current page, traps focus in the mobile drawer, shows Ctrl+K or ⌘K for catalog search, and makes copy-link success and failure visible before resetting.
- Caddy writes JSON access logs at the public edge (visitor IP). NGINX writes JSON access and error logs to container stdout/stderr so `docker compose logs app` includes `/downloads/…`, with `remote` taken from Caddy's `X-Forwarded-For`.
- `/catalog/v1/*.json` uses a short public cache. HTML stays `no-store`. Fingerprinted assets stay immutable.
- About explains how to connect an IDE with an `mcp.json` snippet. The MCP process is a second image in the companion `tool-atlas-mcp` repository.
- Documentation, About, Updates, and Developer Studio load as separate chunks so the catalog page does not wait on those routes.

## Published artifacts

- Source tag: `v1.7.0`
- Linux/amd64 image: `ghcr.io/shalevz923/shalevsoftwaresite:1.7.0`

The tag workflow verifies source and production artifacts and builds and pushes the image. On a public repository it also publishes an OCI provenance attestation. Use the immutable digest reported by the completed workflow rather than a mutable image tag for production deployment.

CI verifies on Node 24. The image builds with Node 26. Confirm both before promotion.

## Product boundary

This image serves only the static public catalog. Developer Studio remains a local, authenticated authoring tool. Tool Atlas MCP is a separate container with its own Caddy edge, `/health` vs `/ready`, optional bearer token, and tool-call audit log. It never sees chat text and never proxies installer bytes.
