# Tool Atlas v1.6.0

`v1.6.0` is the first stable public release of the static Tool Atlas catalog. It graduates the `v1.6.0-beta.1` and `v1.6.0-beta.2` line without shipping Developer Studio in the production image.

## Highlights

- Theme toggle, catalog About page, and the modular-route mark are part of the public static site.
- Catalog-approved GitHub automation is restricted to the repository owner.
- Production images build on Node 26 with Corepack installed explicitly, and serve through nginx 1.31.
- GitHub Actions used for checkout and GHCR publish are current majors; React 19.3, Vite 8.3, and Vitest 5 are the supported toolchain.

## Published artifacts

- Source tag: [`v1.6.0`](https://github.com/ShalevZ923/ShalevSoftwareSite/tree/v1.6.0)
- GitHub release: [`v1.6.0`](https://github.com/ShalevZ923/ShalevSoftwareSite/releases/tag/v1.6.0)
- Linux/amd64 image: `ghcr.io/shalevz923/shalevsoftwaresite:1.6.0`

The tag workflow verifies source and production artifacts, builds and pushes the image, and publishes an OCI provenance attestation. Use the immutable digest reported by the completed workflow rather than a mutable image tag for production deployment.

## Product boundary

This image serves only the static public catalog. Developer Studio remains a local, authenticated authoring tool and is not included in a public deployment.
