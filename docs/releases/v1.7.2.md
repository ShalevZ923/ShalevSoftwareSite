# Tool Atlas v1.7.2

`v1.7.2` is a software-catalog maintenance release that consolidates dependency security and tooling upgrades, enforces dual-lockfile synchronization policy, and solidifies save recovery and catalog verification.

## Changes and Highlights

- **Dependency Upgrades**:
  - Bumped `@babel/core` from 8.0.9 to 8.0.10.
  - Bumped `eslint` from 10.13.0 to 10.14.0.
  - Bumped `globals` from 17.13.0 to 17.14.0.
  - Bumped `vitest` from 5.0.5 to 5.1.0.
  - Bumped `@vitejs/plugin-react` from 6.1.2 to 6.2.1.
  - Bumped `docker/login-action` GitHub Action from 4.7.0 to 4.8.0.
- **Dual-Lockfile Policy & Parity**:
  - Reconciled package-manifest alignment and recorded transitive graph drift in `config/lockfile-differences.json`.
  - Maintained complete parity verification across both npm and pnpm package graphs.
- **Maintenance & Reliability**:
  - Stale-edit rejection, durable save recovery, revision-aware editor saves, structured errors, and stable generated timestamps.
  - Complete verification across unit tests, contract tests, and static distribution checks.

docker pull ghcr.io/shalevz923/shalevsoftwaresite:1.7.2
docker run --rm --read-only --tmpfs /tmp:rw,noexec,nosuid,size=16m -p 127.0.0.1:8080:8080 ghcr.io/shalevz923/shalevsoftwaresite:1.7.2

## Product boundary

This image serves only the static public catalog through unprivileged NGINX. Developer Studio remains a local, authenticated authoring tool.
