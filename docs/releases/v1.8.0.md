# Tool Atlas v1.8.0

`v1.8.0` is the experimental Agent Catalog line. It is built on the `v1.7.0` software-catalog fixes and is not a replacement for that release.

The published image remains `ghcr.io/shalevz923/shalevsoftwaresite:1.7.0`. That image serves only the static software catalog. Agent and skills listings on this branch are for evaluation and are not part of `v1.7.0`.
