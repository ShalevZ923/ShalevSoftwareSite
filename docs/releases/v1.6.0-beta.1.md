# Tool Atlas v1.6.0-beta.1

`v1.6.0-beta.1` is a public prerelease of the static Tool Atlas catalog and Developer Studio improvements.

## Highlights

- Developer Studio now gives field-specific validation guidance, clearer release-target editing, compact guide summaries, and a smaller-screen editor layout.
- Documentation prioritizes resources that match the requested release and uses descriptive guide and file links.
- Catalog headings, saved-tool persistence, hosted-download path handling, and server validation responses are more robust.
