# Code of conduct

This project is a maintained software catalog. Participation in issues,
discussions, pull requests, and security reports is expected to stay
professional and limited to the work.

## Expected behavior

- Keep feedback specific to catalog content, code, documentation, or operations.
- Do not submit licence keys, activation data, private contacts, personal data,
  or installer binaries.
- Do not harass, insult, or impersonate other people.
- Follow maintainer instructions on labels, reviews, and disclosure.

## Unacceptable behavior

- Publishing or requesting secrets, credentials, or private customer data
- Spam, off-topic promotion, or social-engineering the maintainer or reporters
- Personal attacks, discrimination, or threats
- Opening a public issue for a vulnerability that should go through
  [SECURITY.md](./SECURITY.md)

## Enforcement

The maintainer may edit or close contributions, lock conversations, block
accounts, or refuse catalog labels when this standard is not met.

Report conduct problems through GitHub's private contact options for this
repository. Report security issues only through the process in
[SECURITY.md](./SECURITY.md).
