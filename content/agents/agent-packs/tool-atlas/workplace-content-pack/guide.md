## Overview

A Tool Atlas evaluation bundle of the separate Anthropic Internal Comms and Theme Factory skills from revision `34040c9c568585f6929bedeaad110ad08f079624`. The two upstream skills are unchanged. The pack README explains its composition; each skill retains its license.

## Use

Download and verify the ZIP, then extract it. Copy each desired `skills/<name>/` folder into your host's skills directory. The pack folder itself is a container, not a single Agent Skill.

## Support

Evaluation listing. The bundle has been reviewed as an archive, but host loading and support ownership are unverified. [Upstream source](https://github.com/anthropics/skills/tree/34040c9c568585f6929bedeaad110ad08f079624/skills).
