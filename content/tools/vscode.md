# Visual Studio Code

Visual Studio Code is the supported editor for lightweight projects and remote development.

## Install

Install the current stable release, then sign in to Settings Sync with your approved account. The recommended extension profile is available in the internal setup guide.

## When to use it

- TypeScript, documentation, and scripting
- Container or remote workspace development
- Quick repository exploration

## Support

Developer Experience owns the standard extension profile and editor configuration.
