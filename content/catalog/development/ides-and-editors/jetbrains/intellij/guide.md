# IntelliJ IDEA

IntelliJ IDEA is the supported default for JVM development. It is licensed through the internal developer portal.

## Install

1. Download the **Ultimate** edition from [JetBrains](https://www.jetbrains.com/idea/download/).
2. Sign in using your approved JetBrains account.
3. Import the [team settings repository](https://github.com/) when prompted.

> Need an additional plugin? Check its ownership and compatibility before installing it on a managed workstation.

## Standard add-ons

| Add-on | Use | Owner |
| --- | --- | --- |
| SonarLint | Local quality feedback | Quality Engineering |
| Kubernetes | Cluster manifests | Platform Engineering |
| Database Tools | SQL exploration | Data Platform |
